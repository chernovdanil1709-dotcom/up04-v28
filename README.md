Учебная практика по ПМ.04 «Сопровождение и обслуживание программного обеспечения компьютерных систем».

Готовое WPF-приложение (C#, .NET 10) для оформления заявок на узлы метеостанций.
В ходе практики исправлены три дефекта — только в файле `RepairLogic.cs`:

| Дефект | Симптом | Причина | Исправление |
|---|---|---|---|
| D1 | Вход по неизвестному логину (`nobody`) | `?? users.FirstOrDefault()` подставлял первого пользователя | Убран запасной выбор: неизвестный или пустой логин → `null` → отказ |
| D2 | «Назад к каталогу» стирал неподтверждённую заявку | `draft.Clear()` в методе `Back` | Очистка удалена; отмена заявки — отдельная кнопка с подтверждением |
| D3 | Поиск и категория работали через «ИЛИ»; 1000 стояло раньше 200 | `\|\|` вместо `&&`; сортировка по `DiscountPrice.ToString()` | `&&` между категорией и поиском; сортировка по `decimal`, при равной цене — `ThenBy(Id)` |

`OrderService`, модель данных и сохранение в JSON не изменялись.

## Требования

- Windows 10/11
- .NET SDK 10 (проверка: `dotnet --list-sdks`)

## Запуск

В папке проекта (где лежит `Shop.csproj`) открыть PowerShell и выполнить:

```powershell
dotnet run --project .\Shop.csproj -- .\work-data.json
```

Сброс данных в исходное состояние (приложение должно быть закрыто):

```powershell
Copy-Item -LiteralPath baseline.json -Destination work-data.json -Force
```

## Инструкция пользователя

1. **Вход.** Ввести логин `client` (Иванов Иван Иванович) или `buyer` (Петрова Анна Сергеевна) и нажать «Войти». При неверном логине появится сообщение — исправить логин в том же поле.
2. **Поиск.** Над каталогом: строка поиска (по названию или описанию), категория, сортировка по цене. Условия работают вместе.
3. **Карточка.** «Открыть позицию» — карточка узла. «Назад к каталогу» возвращает в каталог, заявка и фильтры сохраняются.
4. **Заявка.** В карточке выбрать исполнение (RS-485 / SDI-12), ввести количество, нажать «Добавить в заявку». Если количество больше остатка или введено неверно — сообщение, исправить поле «Количество».
5. **Отмена.** «Отменить заявку» → «Да» очищает заявку (остатки не меняются), «Нет» — оставляет.
6. **Подтверждение.** «Подтвердить заявку» сохраняет заявку (пользователь, дата, строки) в `work-data.json` и уменьшает остатки. После перезапуска изменения сохраняются.
